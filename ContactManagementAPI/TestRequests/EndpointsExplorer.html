Contact Management API - Endpoints Explorer

Authentication

POST /api/auth/login

Authenticates a user and generates a JWT token

Request body:

{
  "username": "string",
  "password": "string"
}

Responses:

200 - Returns the JWT token and user information
401 - If authentication fails

POST /api/auth/token

Gets a plain text JWT token for a user

Request body:

{
  "username": "string",
  "password": "string"
}

Responses:

200 - Returns the JWT token as plain text
401 - If authentication fails

Contacts API v1

GET /api/v1/contacts v1.0

Gets all contacts with optional filtering and sorting

Query parameters:

name (string) - Filter by contact name
city (string) - Filter by city
state (string) - Filter by state (2 letter code)
sortBy (string) - Sort by field (name, city, state)
order (string) - Sort order (asc or desc)

Responses:

200 - Returns the list of contacts
403 - If the user doesn't have permission
500 - If there was an internal server error

Contacts API v2

GET /api/v2/contacts v2.0

Gets all contacts with optional filtering and sorting (v2 with enhanced metadata)

Query parameters:

name (string) - Filter by contact name
city (string) - Filter by city
state (string) - Filter by state (2 letter code)
sortBy (string) - Sort by field (name, city, state)
order (string) - Sort order (asc or desc)

Responses:

200 - Returns the list of contacts with metadata
401 - If the user is not authenticated
403 - If the user doesn't have permission
500 - If there was an internal server error

GET /api/v2/contacts/summary v2.0

Gets a summary of contacts by state (v2 only endpoint)

Responses:

200 - Returns the summary statistics
403 - If the user doesn't have permission
500 - If there was an internal server error
